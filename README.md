# WEF – WhatsApp Export Forensics

Programma per Windows che acquisisce le chat esportate da WhatsApp (iPhone e Android, in qualsiasi lingua) e produce documenti verificabili a uso forense: archivio dei messaggi, Excel con collegamenti agli allegati, rapporti PDF con miniature, impronte MD5 e SHA-256, trascrizione locale dei messaggi vocali.

## Scarica

**[Scarica l'ultima versione (WEF-win-Setup.exe)](https://github.com/luigisettembrini/wef/releases/latest/download/WEF-win-Setup.exe)**

Requisiti: Windows 10 o 11 a 64 bit. Non servono diritti di amministratore né altri programmi.

1. Avvia il file scaricato: il programma si installa e si apre.
2. Se il browser segnala che il file "non viene scaricato spesso", scegli *Mantieni* / *Conserva comunque*.
3. Se compare l'avviso di Windows SmartScreen, scegli *Ulteriori informazioni* → *Esegui comunque*.

Le versioni successive vengono proposte dal programma stesso all'avvio.
